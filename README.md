Tiny Kitchen Rush: a complete 2D canvas cooking game that plays offline in a desktop browser. Read the ticket on the order board, grill patties and eggs before they burn, stack the plate on the assembly counter and serve before the customer's patience runs out. Static files under game/, handed in by main.ts.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts — or open game/index.html in a browser to play
```
